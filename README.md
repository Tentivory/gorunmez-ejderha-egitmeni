# GÖRÜNMEZ EJDERHA EĞİTMENİ

## Dünyanın En Önemli Yazılım Projesi (Muhtemelen)

Bu repository, insanlık tarihinin en büyük bilimsel atılımlarından birini barındırmaktadır:  
**Görünmez ejderhaları eğitmek.**

Evet, okudunuz. Görünmez. Ejderha. Eğitmek.

### Neden Bu Kadar Önemli?

Çünkü görünmez ejderhalar her yerde.  
Siz fark etmiyorsunuz. Ben fark etmiyorum. Kimse fark etmiyor.  
Ama onlar oradalar. Ve disiplinsizler.

Bu yazılım sayesinde:
- Ejderhanız oturmayı öğrenebilir (göremezsiniz ama öğrendiğine emin olun)
- Ateş püskürtme komutunu alabilir (ısıyı hissedebilirsiniz belki)
- İnsanları yememeyi öğrenebilir (çok kritik)
- Hazinenizi koruyabilir (hangi hazine? bilmiyoruz)

### Kurulum

```bash
git clone https://github.com/Tentivory/gorunmez-ejderha-egitmeni.git
cd gorunmez-ejderha-egitmeni
python3 ejderha_egitici.py
```

Python 3 yeterlidir. Başka hiçbir şeye ihtiyacınız yoktur.  
Ejderhanız zaten yanınızda (muhtemelen).

### Kullanım

Programı çalıştırın. Menüden seçim yapın.  
Ejderhanız tepki verecektir.  
Tepkiyi göremeyeceksiniz. Bu başarıdır.

### Bilimsel Dayanak

- %100 görünmezlik oranı
- %0 kanıt
- %100 inanç gerekliliği
- Sonsuz potansiyel (ölçülemez çünkü görünmez)

### Uyarılar

- Ejderhanızı asla doğrudan gözle temasa sokmaya çalışmayın. Zaten göremezsiniz.
- Ateş püskürtme komutu sonrası evinizi havalandırın (ihtiyaten).
- Bu yazılım herhangi bir gerçek ejderha eğitimi vaat etmez. Sadece görünmez olanları.

### Katkıda Bulunma

Pull request açabilirsiniz.  
Ama değişikliklerin görünmez olması tercih edilir.
